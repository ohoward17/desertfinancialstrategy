# Desert Financial Strategy Dashboard

A hypothetical strategy and ALM dashboard built from public Desert Financial Credit Union data and modeled assumptions.

## What it includes

- Executive financial dashboard
- ALM and interest rate risk views
- Financial statements and key ratios
- Strategy scenario for the "First Borrowing Moment"
- AI Analyst for querying the modeled data

## Strategy scenario

The strategy model explores whether winning a young adult's first major borrowing relationship could lead to a broader banking relationship over time.

The scenario is hypothetical. Modeled assumptions are kept separate from reported financial data.

## Files

- `index.html` — self-contained dashboard
- `DFCU_ALM_Workbook.xlsx` — supporting financial model and source calculations
- `package.json` — project dependencies and scripts

## Run locally

Open `index.html` in a browser.
